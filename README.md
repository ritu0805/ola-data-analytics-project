# Ola Ride Booking Data Analysis

## Project Overview

This project focuses on analyzing Ola ride booking data to understand booking trends, cancellations, revenue, ride distance, payment methods, and customer and driver ratings.

The project uses SQL for data analysis and Power BI for creating an interactive dashboard.

## Objective

The main objectives of this project are:

* Analyze successful and cancelled bookings
* Understand ride booking trends
* Analyze cancellation reasons
* Compare ride distance across vehicle types
* Analyze customer and driver ratings
* Understand revenue by payment method
* Identify top customers based on booking activity
* Analyze incomplete rides and their reasons

## Tools & Technologies

* **SQL (PostgreSQL)** – Data querying and analysis
* **Microsoft Excel** – Data handling and preparation
* **Power BI** – Data visualization and dashboard creation
* **GitHub** – Project documentation and version management

## SQL Analysis

The project includes SQL queries to analyze:

* Successful bookings
* Average ride distance by vehicle type
* Customer cancellations
* Top customers by number of rides
* Driver cancellation reasons
* Minimum and maximum driver ratings
* UPI payment bookings
* Average customer ratings by vehicle type
* Total successful booking value
* Incomplete rides and their reasons

## Power BI Dashboard

The Power BI dashboard provides visual analysis of:

* Ride volume over time
* Booking status
* Vehicle types and ride distance
* Customer ratings
* Driver ratings
* Cancellation reasons
* Revenue by payment method
* Top customers
* Ride distance distribution

## Key Insights

The analysis helps understand:

* Booking performance and ride volume
* Reasons behind customer and driver cancellations
* Revenue generated from successful rides
* Customer and driver service ratings
* Ride distance patterns across vehicle types
* Customer booking behavior
